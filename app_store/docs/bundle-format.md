# Bundle format

`app.yaml` is the executable runtime contract. `bundle.json` contains
distribution and presentation metadata only.

Important fields:

- `id`, `name`, and `version` must exactly match `app.yaml`.
- `summary` is the short app-store card text; `description` is the detail text.
- `authors`, `license`, and `links` preserve attribution and give users a place
  to report problems.
- `compatibility` declares the minimum controller version and tested Linux
  platforms.
- `icon` and `screenshots` are paths inside the package.
- `package` is generated by `storectl`; contributors do not calculate it by
  hand.

The payload is every regular file in the app directory except `bundle.json`.
Symbolic links and special files are rejected. Each file records its SHA-256
and byte size. `payload_sha256` is SHA-256 over the following UTF-8 record for
each path in bytewise sorted order:

```text
<path>\n<file-sha256>\n<size-bytes>\n
```

The top-level `index.json` records the hash and size of each complete
`bundle.json`. This allows a controller to fetch one small index, render the
catalogue, and verify the selected bundle and every payload file before
installation.

The JSON Schemas are documentation and editor support. `storectl` plus the
core Go manifest validator are authoritative.
